Assets de imagen para el proyecto Mariposa de Manos.

Coloca aquí tu archivo de la mariposa:
  assets/images/butterfly.png   (PNG con fondo transparente, recomendado)

Si no encuentras un PNG, el proyecto incluye un placeholder en SVG:
  assets/images/butterfly.svg

p5.js intentará cargar butterfly.png primero; si no existe, usará butterfly.svg.
Si ninguno existe, se dibuja una mariposa vectorial de respaldo dentro del sketch.

Dimensiones sugeridas para el PNG: al menos 200x200 px, fondo transparente.
